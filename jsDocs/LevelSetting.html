Class: LevelSetting

LevelSetting(countOfEnemies, minBottles, minCoins, gameLengthFrames, difficulty)

This class represents the settings for a game level, extending LevelProperties. It allows configuration of enemy count, item ranges, game length, and difficulty.

Constructor

new LevelSetting(countOfEnemies, minBottles, minCoins, gameLengthFrames, difficulty)

Parameters:
Name Type Description
countOfEnemies number The number of enemies in the level.
minBottles number The minimum number of bottles on screen.
minCoins number The minimum number of coins on screen.
gameLengthFrames number The length of the game in frames.
difficulty string The difficulty level of the game (e.g., 'easy', 'medium', 'hard').
